# Jàng – démo

Prototype cliquable de Jàng, logiciel de gestion pour les écoles privées du Sénégal.

Démo en ligne : https://jang-sn.github.io/jang-demo/

Données d'exemple uniquement : rien n'est sauvegardé, envoyé ni payé.

## Jeu : Teranga City

Petit jeu de ville en monde ouvert vu du dessus (`jeu.html`) : marcher, prendre des voitures, faire des livraisons contre la montre, ramasser des billets et échapper à la police.

Jouer : https://jang-sn.github.io/jang-demo/jeu.html (ou ouvrir `jeu.html` dans un navigateur).
Clavier : flèches / ZQSD / WASD, `E` pour monter ou descendre, `Espace` pour le frein à main. Sur mobile : joystick et boutons à l'écran.
