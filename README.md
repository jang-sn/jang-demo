## Wergui SN – stock pharmacie (démo)

Prototype cliquable d'un logiciel de gestion de stock pour les pharmacies : alertes de péremption par lot, caisse (sortie FEFO, tiers payant, Wave / Orange Money), suggestions de commande par grossiste, réception avec lots et dates, inventaire tournant, abonnement à 15 000 F/mois payé en Mobile Money.

Démo en ligne : https://jang-sn.github.io/jang-demo/pharmacie/

Données d'exemple uniquement : rien n'est sauvegardé, envoyé ni payé.
